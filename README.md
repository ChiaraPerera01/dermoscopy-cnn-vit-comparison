# Skin Lesion Classification with XAI & Uncertainty

MSc thesis project comparing CNN, attention-enhanced CNN, and Vision Transformer
architectures for skin lesion classification, with explainability (Grad-CAM,
attention maps) and uncertainty estimation (MC Dropout, temperature scaling).

## Setup

1. Create environment: `conda create -n skinlesion python=3.11 -y`
2. Activate: `conda activate skinlesion`
